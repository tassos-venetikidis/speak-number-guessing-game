# Speak Number Guessing Game

Guess the number that the computer is thinking by speaking it out. By leveraging the Speech Recognition service of the Web Speech API, the game gives you feedback if you are out of bounds (number should be between 1 and 100), if you are too low, too high, or if you have won by figuring it out. Speech input that is not a number also is acknowledged by the game. If you have won, press the play again button to restart the game.

Made with:

- HTML
- CSS
- vanilla JavaScript
- MVP: SpeechRecognition of the Web Speech API!
